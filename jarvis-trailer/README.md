# JARVIS Trailer

Eigenständiger 80-Sekunden-Promo-Film in 1080×1920 bei 30 fps. Die Filmkomposition ist vom Produktcode getrennt und verwendet kontrollierte Demo-Daten, damit keine privaten Kalender-, Standort- oder Kontodaten im Video landen.

Rendern: `npm install && bash make-soundtrack.sh && npm run render`

GitHub Actions erzeugt `JARVIS-Trailer-1080x1920` als MP4-Artefakt.
